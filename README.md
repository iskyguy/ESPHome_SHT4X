# ESPHome SHT4x

KiCad hardware project for an ESPHome-oriented temperature and humidity sensor built around an ESP32-C6-WROOM-1-N8 and a Sensirion SHT40. The design includes USB-C, a BQ25628E battery charger, and an XC6220 3.3 V regulator.

Open [the project](hardware/ESPHome_SHT4X/ESPHome_SHT4X.kicad_pro) in KiCad 10. Schematic and PCB sources, review PDFs, and a 3D export are included. Some imported component libraries and models must be installed locally, and existing library paths may need adjustment.

Work in progress; no ESPHome firmware configuration is included.
